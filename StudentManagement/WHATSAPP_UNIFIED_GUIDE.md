# دليل إعداد خدمة WhatsApp الموحدة

تم تحديث نظام إدارة التلاميذ PROGTALAMID ليدعم **خدمات WhatsApp متعددة** من خلال واجهة موحدة. يمكنك الآن اختيار الخدمة المناسبة لاحتياجاتك.

---

## الخدمات المدعومة

### 1.   (الموصى به) ✅

**المميزات:**
- مفتوح المصدر ومجاني تماماً
- سهل التثبيت والإعداد
- يعمل على خادمك الخاص
- استقرار عالي وموثوقية ممتازة
- دعم Docker لسهولة النشر
- لا توجد قيود على عدد الرسائل

**متطلبات الإعداد:**
- خادم بـ Docker (يمكن استخدام AWS, DigitalOcean, VPS أي نوع)
- عنوان الخادم: `https://api.progtalamid.com`
- اسم الجلسة: `default` (أو أي اسم تختاره)
- مفتاح API (اختياري للحماية)

**طريقة الإعداد:**
1. اذهب إلى **الإعدادات** → **إعدادات واتساب**
2. اختر نوع الخدمة: ** **
3. أدخل البيانات التالية:
   - **عنوان خادم  **: `https://api.progtalamid.com`
   - **اسم الجلسة**: `default`
   - **مفتاح API** (اختياري): اتركه فارغاً إذا لم يكن الخادم محمياً
4. احفظ الإعدادات
5. اضغط على **اختبار الاتصال** للتأكد من نجاح الربط


### 2. Evolution API

**المميزات:**
- حل قوي ومتقدم
- دعم ميزات WhatsApp الكاملة
- مفتوح المصدر
- يعمل على خادمك الخاص

**متطلبات الإعداد:**
- خادم Evolution API
- عنوان الخادم
- اسم المثيل (Instance Name)
- مفتاح API للمثيل

**طريقة الإعداد:**
1. اختر نوع الخدمة: **Evolution API**
2. أدخل:
   - عنوان خادم Evolution API
   - اسم المثيل
   - مفتاح API
3. احفظ واختبر الاتصال

**مثال على بيانات الربط:**
```
نوع الخدمة: Evolution API
عنوان الخادم: https://evolution.example.com
اسم المثيل: school_alamal
مفتاح API: B6477yAa-52Ca-4000-B477-23AG2F9466AO
```

### 3. Green API

**المميزات:**
- خدمة سحابية جاهزة
- لا تحتاج خادم خاص
- سهولة الإعداد

**العيوب:**
- خدمة مدفوعة
- قد تكون هناك قيود على عدد الرسائل

**طريقة الإعداد:**
1. اختر نوع الخدمة: **Green API**
2. أدخل:
   - معرف المثيل (Instance ID)
   - رمز الوصول (API Token)
3. احفظ واختبر الاتصال

---

### 4. CallMeBot / WhapiPlus

**المميزات:**
- خدمة بسيطة ومجانية
- لا تحتاج خادم

**العيوب:**
- موثوقية أقل
- ميزات محدودة

**طريقة الإعداد:**
1. اختر نوع الخدمة: **CallMeBot**
2. أدخل:
   - معرف المثيل
   - رمز الوصول
3. احفظ واختبر الاتصال

## استخدام النظام

### 1. إعداد الخدمة

بعد اختيار وإعداد الخدمة المناسبة:
1. اذهب إلى **الإعدادات** → **إعدادات واتساب**
2. اختر نوع الخدمة من القائمة المنسدلة
3. أدخل البيانات المطلوبة
4. فعّل **تفعيل إرسال الإشعارات تلقائياً**
5. احفظ الإعدادات

### 2. اختبار الإعداد

قبل استخدام النظام للإرسال الفعلي:
1. اضغط على **اختبار الاتصال** للتأكد من الربط
2. في قسم **اختبار إرسال رسالة**:
   - أدخل رقم هاتف تجريبي (مثال: 0662707072)
   - اضغط **إرسال تجريبي**
   - تحقق من وصول الرسالة على WhatsApp

### 3. إرسال الرسائل من البرنامج

الآن يمكنك إرسال رسائل WhatsApp من أي صفحة في البرنامج:

#### أ) إرسال إشعارات الغياب
1. اذهب إلى **إدارة الغيابات**
2. حدد التلاميذ الغائبين
3. اضغط **إرسال إشعارات واتساب**
4. ستُرسل الرسائل تلقائياً لأولياء الأمور

#### ب) التواصل عبر واتساب
1. اذهب إلى **التواصل عبر واتساب**
2. اختر طريقة الإرسال:
   - **حسب القسم**: إرسال لقسم معين
   - **حسب المستوى**: إرسال لمستوى دراسي
   - **للجميع**: إرسال لكل التلاميذ
   - **مخصص**: اختيار مستلمين محددين
3. اختر نوع المستلم:
   - **التلميذ**: يُرسل لرقم التلميذ
   - **ولي الأمر**: يُرسل لرقم ولي الأمر
4. اكتب الرسالة أو اختر من القوالب
5. اضغط **إرسال الرسائل**

## معلومات تقنية

### تنسيق أرقام الهواتف

النظام يقوم بتنسيق الأرقام تلقائياً:
- **إدخال**: `0662707072`
- **بعد التنسيق**: `212662707072@c.us` (لـahw/Green API)
- **بعد التنسيق**: `212662707072@s.whatsapp.net` (لـ Evolution API)

### المتغيرات في الرسائل

يمكنك استخدام المتغيرات التالية في رسائلك:
- `{STUDENT_NAME}` - اسم التلميذ
- `{LEVEL}` - المستوى الدراسي
- `{SECTION}` - القسم
- `{DATE}` - التاريخ الحالي
- `{TIME}` - الوقت الحالي

**مثال:**
```
السلام عليكم
عزيزي ولي أمر التلميذ {STUDENT_NAME}
نفيدكم بأن ابنكم تغيب اليوم {DATE}
```

سيتم استبدال المتغيرات تلقائياً عند الإرسال.

## استكشاف الأخطاء

### مشكلة: "لم يتم العثور على إعدادات WhatsApp نشطة"
**الحل:**
1. تأكد من حفظ الإعدادات
2. تأكد من تفعيل خانة "تفعيل إرسال الإشعارات"
3. أعد تحميل الصفحة

### مشكلة: "فشل الاتصال بالخادم"
**الحل:**
1. تحقق من صحة عنوان الخادم
2. تأكد من أن الخادم يعمل ويمكن الوصول إليه
3. تحقق من صحة مفتاح API إذا كان مطلوباً

### مشكلة: "فشل إرسال الرسالة"
**الحل:**
1. تأكد من صحة رقم الهاتف
2. تحقق من أن الجلسة متصلة على الخادم
3. جرب إرسال رسالة تجريبية أولاً
4. راجع سجلات console في المتصفح (F12)

### مشكلة: رسالة 401 Unauthorized (WAHA)
**الحل:**
1. تحقق من صحة مفتاح API المدخل
2. إذا كان الخادم غير محمي، اترك حقل مفتاح API فارغاً

## الأمان وأفضل الممارسات

### حماية البيانات
- لا تشارك مفاتيح API مع أحد
- استخدم HTTPS دائماً للاتصال بالخوادم
- غيّر مفاتيح API بشكل دوري

### تجنب الحظر
- لا ترسل أكثر من 40 رسالة في الدقيقة
- النظام يضيف تأخير 1.5 ثانية تلقائياً بين الرسائل
- تجنب إرسال رسائل spam أو محتوى مكرر

### نصائح للاستخدام الأمثل
- اختبر الإعدادات قبل الإرسال الجماعي
- استخدم القوالب للرسائل المتكررة
- راجع أرقام الهواتف قبل الإرسال
- احتفظ بنسخة احتياطية من الإعدادات

## الدعم الفني

في حال واجهتك أي مشكلة:
1. راجع قسم **استكشاف الأخطاء** أعلاه
2. افتح console المتصفح (F12) وابحث عن رسائل الخطأ
3. تواصل مع الدعم الفني مع إرفاق:
   - نوع الخدمة المستخدمة
   - رسالة الخطأ كاملة
   - لقطة شاشة للمشكلة

## ملاحظات مهمة

### بخصوصahw
- تم إعداد الخادم على `https://api.progtalamid.com`
- الجلسة الافتراضية اسمها `default`

- يجب إنشاء instance أولاً على خادم Evolution
- احصل على API key الخاص بالـ instance
- تأكد من أن الـ instance متصل ومفعّل

### بخصوص تنسيق الأرقام
- أدخل الأرقام المغربية بدون رمز الدولة: `0662707072`
- النظام يضيف `212` تلقائياً
- لأرقام دول أخرى، أدخل الرقم الكامل مع رمز الدولة بدون `+`
