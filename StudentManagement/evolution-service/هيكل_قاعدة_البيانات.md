## 🗂️ تفاصيل الجداول

### 1. evolution_instances

**الوظيفة:** تخزين إعدادات Instances الواتساب. كل Instance يمثل اتصال واتساب منفصل.

**الأعمدة:**

| العمود | النوع | وصف |
|--------|------|------|
| `id` | uuid | معرّف فريد للـ instance |
| `name` | text | اسم Instance (فريد، مثل: school_system) |
| `token` | text | رمز المصادقة |
| `phone_number` | text | رقم الواتساب المتصل |
| `status` | text | حالة الاتصال (connected, disconnected) |
| `qrcode` | text | كود QR للربط |
| `profile_name` | text | اسم الحساب في الواتساب |
| `profile_picture_url` | text | رابط صورة الملف الشخصي |
| `created_at` | timestamptz | تاريخ الإنشاء |
| `updated_at` | timestamptz | تاريخ آخر تحديث |

**مثال على الاستخدام:**
```sql
-- الحصول على جميع Instances المتصلة
SELECT name, status, phone_number, profile_name
FROM evolution_instances
WHERE status = 'connected';
```

---

### 2. evolution_messages

**الوظيفة:** تسجيل جميع رسائل الواتساب (المرسلة والمستقبلة) للمراجعة والتاريخ.

**الأعمدة:**

| العمود | النوع | وصف |
|--------|------|------|
| `id` | uuid | معرّف فريد للرسالة |
| `instance_id` | uuid | مرجع لـ evolution_instances |
| `message_id` | text | معرّف رسالة الواتساب |
| `remote_jid` | text | رقم المستلم/المرسل بصيغة JID |
| `from_me` | boolean | true إذا أرسلناها، false إذا استقبلناها |
| `message_type` | text | النوع: text, image, audio, video, document |
| `message_content` | jsonb | محتوى الرسالة الكامل (JSON) |
| `message_text` | text | النص المستخرج للاستعلام السريع |
| `status` | text | حالة الرسالة: pending, sent, delivered, read, error |
| `timestamp` | timestamptz | وقت الرسالة |
| `created_at` | timestamptz | وقت التسجيل في القاعدة |

**مثال على الاستخدام:**
```sql
-- الحصول على جميع الرسائل المرسلة اليوم
SELECT message_text, status, timestamp
FROM evolution_messages
WHERE from_me = true
  AND DATE(timestamp) = CURRENT_DATE
ORDER BY timestamp DESC;
```

### 3. evolution_contacts

**الوظيفة:** تخزين معلومات جهات الاتصال في الواتساب.

**الأعمدة:**

| العمود | النوع | وصف |
|--------|------|------|
| `id` | uuid | معرّف فريد لجهة الاتصال |
| `instance_id` | uuid | مرجع لـ evolution_instances |
| `remote_jid` | text | رقم جهة الاتصال بصيغة JID |
| `push_name` | text | الاسم كما يظهر في الواتساب |
| `profile_picture_url` | text | صورة الملف الشخصي |
| `is_business` | boolean | حساب تجاري؟ |
| `last_seen` | timestamptz | آخر ظهور |
| `created_at` | timestamptz | أول ظهور |
| `updated_at` | timestamptz | آخر تحديث |

**قيود:** UNIQUE(instance_id, remote_jid) - لمنع التكرار

|--------|------|------|

## 🔒 الأمان والصلاحيات

### Row Level Security (RLS)

جميع الجداول مُفعّل عليها RLS بالسياسات التالية:

```sql
-- قراءة عامة (مطلوب لعمل Evolution API)
CREATE POLICY "Public read access"
  ON [table] FOR SELECT
  TO public
  USING (true);

-- كتابة للمستخدمين المصادق عليهم فقط
CREATE POLICY "Authenticated users can insert/update"
  ON [table] FOR INSERT/UPDATE
  TO authenticated
  WITH CHECK (true);
```

**لماذا القراءة العامة؟**
- Evolution API يعمل على AWS EC2 بدون مصادقة Supabase
- يتصل مباشرة عبر PostgreSQL connection
- القراءة لا تكشف بيانات حساسة
- الكتابة محمية بمصادقة

## ⚡ Triggers التلقائية

جميع الجداول (عدا evolution_messages) لديها trigger تلقائي لتحديث `updated_at`:

```sql
CREATE OR REPLACE FUNCTION update_evolution_timestamp()
RETURNS TRIGGER AS $$
BEGIN
  NEW.updated_at = now();
  RETURN NEW;
END;
$$ LANGUAGE plpgsql;
```

### 3. إحصائيات النشاط

```sql
SELECT
  i.name as instance_name,
  COUNT(m.id) as message_count,
  MAX(m.timestamp) as last_message
FROM evolution_instances i
LEFT JOIN evolution_messages m ON i.id = m.instance_id
GROUP BY i.id, i.name
ORDER BY last_message DESC;
```

### 4. حذف الرسائل القديمة (أقدم من 30 يوم)

```sql
DELETE FROM evolution_messages
WHERE created_at < NOW() - INTERVAL '30 days';
```

## 📝 ملاحظات مهمة

1. **أسماء Instances:** يجب أن تكون فريدة في القاعدة. استخدم أسماء وصفية مثل "school_system", "admin_account"

2. **صيغة Remote JID:** الواتساب يستخدم صيغة JID: `countrycode+number@s.whatsapp.net` (مثال: `212600000000@s.whatsapp.net`)

3. **Message Content:** عمود `message_content` يخزن هيكل رسالة الواتساب الكامل بصيغة JSONB للمرونة

4. **Session Data:** يحتوي على رموز مصادقة مشفرة. لا تعرضه أو تعدله يدوياً أبداً

5. **Cascade Deletes:** حذف instance يحذف تلقائياً جميع الرسائل، جهات الاتصال، المحادثات، Webhooks، والجلسات المرتبطة

6. **Timestamps:** جميع الأوقات مخزنة بتوقيت UTC (timestamptz)

## 🔍 استكشاف الأخطاء

### المشكلة: FATAL: Tenant or user not found

**الحل:**
- تأكد من استخدام اسم المستخدم الصحيح للـ Pooler: `postgres.benjzaxxkcjwnrfllvel`
- **ليس** `postgres` فقط

### المشكلة: P1001: Can't reach database server

**الحل:**
1. تحقق من IP السيرفر مضاف في Supabase:
   ```bash
   curl -4 ifconfig.me
   ```
2. اذهب إلى: Supabase Dashboard → Settings → Database → Network Restrictions
3. أضف IP السيرفر

### المشكلة: Connection timeout

**الحل:**
- استخدم Direct Connection مؤقتاً للاختبار
- تحقق من إعدادات الجدار الناري (Firewall)
