## 🛠️ استخدام لوحة تحكم المطور

### 1. توليد أكواد جديدة

#### أكواد تجريبية:
1. اختر "ترخيص تجريبي"
2. اختر الخطة (Basic, Pro, Expert)
3. حدد المدة (افتراضياً 7 أيام)
4. عدد الاستخدامات (1 أو أكثر)

**خيارات متقدمة للأكواد التجريبية:**
- ✅ **استخدامات غير محدودة**: يمكن استخدام الكود عدة مرات
- ✅ **للمطور فقط**: كود خاص بالمطور
- ✅ **يمكن إعادة التفعيل**: إمكانية استخدامه على أجهزة مختلفة

#### أكواد كاملة:
1. اختر "ترخيص كامل"
2. اختر الخطة
3. حدد المدة (30، 180، 365 يوم)
4. عدد الاستخدامات (عادةً 1)

### 2. إدارة الأكواد الموجودة

في جدول التراخيص، يمكنك:

**الإجراءات المتاحة:**
- 🔄 **إعادة التفعيل** (أيقونة التحديث): إلغاء تفعيل الكود ليمكن استخدامه مرة أخرى
- ✅ **تفعيل/تعطيل** (أيقونة الدائرة): تفعيل أو تعطيل الكود
- 🗑️ **حذف** (أيقونة سلة المهملات): حذف الكود نهائياً
- 📋 **نسخ** (أيقونة النسخ): نسخ الكود بنقرة واحدة

### 3. عرض سجل التفعيلات

سيتم تسجيل كل محاولة تفعيل تلقائياً في جدول `activation_logs` مع:
- الكود المستخدم
- بصمة الجهاز
- نجاح/فشل المحاولة
- رسالة الخطأ (إن وجدت)
- التاريخ والوقت

## 💻 للمطورين: استخدام الكود برمجياً

### التحقق من صلاحية الكود

```typescript
import { licenseManager } from './utils/licenseManager';

const result = await licenseManager.validateAndActivateLicense('TRIAL-DEV-UNLIMITED-2025');

if (result.success) {
  console.log('تم التفعيل بنجاح:', result.message);
} else {
  console.error('فشل التفعيل:', result.message);
}
```

### التحقق من حالة الترخيص

```typescript
const status = await licenseManager.checkLicenseStatus();

if (status.isValid) {
  console.log('الترخيص صالح');
} else if (status.needsActivation) {
  // عرض شاشة التفعيل
} else {
  console.error('انتهت صلاحية الترخيص');
}
```

### إلغاء التفعيل (للمطور فقط)

```typescript
const success = await licenseManager.deactivateLicense(
  'TRIAL-DEV-UNLIMITED-2025',
  'BGA161' // كلمة مرور المطور
);

if (success) {
  console.log('تم إلغاء التفعيل');
}
```

## 🔍 استعلامات SQL مفيدة

### عرض جميع الأكواد التجريبية

```sql
SELECT license_key, plan_name, duration_days, current_uses, max_uses, unlimited_uses
FROM subscription_licenses
WHERE is_trial_code = true
ORDER BY created_at DESC;
```

### عرض الأكواد المفعلة حالياً

```sql
SELECT license_key, plan_name, device_fingerprint, activated_at
FROM subscription_licenses
WHERE device_fingerprint IS NOT NULL
ORDER BY activated_at DESC;
```

### عرض سجل محاولات التفعيل الفاشلة

```sql
SELECT license_key, error_message, created_at
FROM activation_logs
WHERE success = false
ORDER BY created_at DESC
LIMIT 20;
```

### إعادة تعيين كود معين

```sql
UPDATE subscription_licenses
SET device_fingerprint = NULL,
    activated_at = NULL
WHERE license_key = 'TRIAL-DEV-UNLIMITED-2025';
```
