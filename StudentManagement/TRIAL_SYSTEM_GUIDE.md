# دليل نظام التجربة المجانية الذكي - BGAstudents

## نظرة عامة

تم تطوير نظام تجريبي متقدم وآمن للغاية يسمح للمستخدمين بتجربة البرنامج لمدة 7 أيام بدون الحاجة لإدخال أي كود. النظام محمي بشكل قوي ضد جميع أنواع التلاعب ويتتبع إحصائيات الاستخدام بشكل تلقائي.

## المميزات الرئيسية

### 1. تجربة مجانية بدون كود
- الضغط على زر واحد فقط "ابدأ التجربة المجانية"
- البرنامج يعمل فوراً بكامل مميزاته
- لا حاجة لإدخال معلومات شخصية
- مدة التجربة: 7 أيام كاملة

### 2. حماية متقدمة ضد التلاعب

#### أ) حماية من تغيير التوقيت
- مزامنة دائمة مع وقت خادم Supabase
- كشف أي فرق أكبر من 5 دقائق
- إيقاف البرنامج فوراً عند اكتشاف تلاعب
- تسجيل كل محاولة تلاعب في قاعدة البيانات

#### ب) حماية من الوضع الخاص (Incognito)
- كشف تلقائي للوضع الخاص
- فحص storage quota
- فحص IndexedDB
- منع الاستخدام في الوضع الخاص

#### ج) حماية من تغيير المتصفح
- بصمة فريدة معقدة للجهاز
- Canvas Fingerprinting محسّن
- WebGL Fingerprinting
- Audio Fingerprinting
- تخزين مشفر محلياً وعلى Supabase

#### د) حماية من مسح البيانات
- نسخة احتياطية على Supabase
- استعادة تلقائية للحالة
- منع تجربة جديدة على نفس الجهاز
- تتبع عبر بصمة الجهاز

### 3. تتبع شامل للإحصائيات

#### للمطور
- عدد المستخدمين الإجمالي
- عدد المستخدمين النشطين
- عدد التجارب المنتهية
- عدد المتحولين لمشتركين مدفوعين
- معدل التحويل (Conversion Rate)
- تجارب اليوم
- أكثر الميزات استخداماً
- سجل كامل لكل مستخدم

#### البيانات المجمعة
- وقت بداية التجربة
- وقت انتهاء التجربة
- عدد مرات فتح البرنامج
- آخر نشاط
- معلومات المتصفح
- حالة التحويل

### 4. واجهة مستخدم احترافية

#### شاشة التفعيل
- زر كبير وواضح "ابدأ التجربة المجانية"
- تصميم جذاب بألوان متدرجة
- إمكانية إدخال كود تفعيل بديل
- رسائل واضحة ومباشرة

#### شريط العد التنازلي
- يظهر أعلى الشاشة أثناء التجربة
- عرض الأيام والساعات المتبقية
- تغيير اللون حسب الوقت المتبقي:
  - أخضر: 7-5 أيام
  - برتقالي: 4-2 أيام
  - أحمر: أقل من يومين
- شريط تقدم مرئي
- زر "اشترك الآن"

#### شاشة انتهاء التجربة
- تصميم احترافي وجذاب
- عرض 3 خطط اشتراك (Basic, Pro, Expert)
- بطاقات تفصيلية لكل خطة
- معلومات الاتصال واضحة
- زر "لديك كود؟" للعودة للتفعيل

## البنية التقنية

### 1. قاعدة البيانات (Supabase)

#### جدول trial_sessions
```sql
- id (uuid) - معرف فريد
- device_fingerprint (text, unique) - بصمة الجهاز
- trial_started_at (timestamptz) - بداية التجربة
- trial_expires_at (timestamptz) - نهاية التجربة
- is_expired (boolean) - هل انتهت
- session_count (integer) - عدد مرات الفتح
- last_activity (timestamptz) - آخر نشاط
- browser_info (jsonb) - معلومات المتصفح
- ip_address (text) - عنوان IP
- converted_to_paid (boolean) - تحول لمشترك
```

#### جدول user_analytics
```sql
- id (uuid) - معرف فريد
- device_fingerprint (text) - بصمة الجهاز
- session_type (text) - trial/paid/developer
- action_type (text) - نوع الإجراء
- action_details (jsonb) - تفاصيل
- timestamp (timestamptz) - الوقت
- user_agent (text) - معلومات المتصفح
```

#### جدول server_time_checks
```sql
- id (uuid) - معرف فريد
- device_fingerprint (text) - بصمة الجهاز
- client_time (timestamptz) - وقت العميل
- server_time (timestamptz) - وقت الخادم
- time_difference_seconds (integer) - الفرق
- is_suspicious (boolean) - هل مشبوه
```

## سير العمل (Workflow)

### 1. أول مرة يفتح المستخدم البرنامج

```
1. يظهر شاشة التفعيل
2. يرى زر "ابدأ التجربة المجانية - 7 أيام"
3. يضغط على الزر
4. النظام يقوم بـ:
   - توليد بصمة فريدة للجهاز
   - فحص الوضع الخاص
   - فحص تزامن الوقت
   - إنشاء جلسة في Supabase
   - حفظ البيانات محلياً
   - تسجيل في الإحصائيات
5. البرنامج يعمل فوراً
```

### 2. أثناء فترة التجربة

```
- شريط العد التنازلي يظهر أعلى الشاشة
- المستخدم يستخدم البرنامج بحرية
- كل مرة يفتح البرنامج:
  - التحقق من تزامن الوقت
  - التحقق من صلاحية التجربة
  - تحديث عداد الجلسات
  - تسجيل النشاط
```

### 3. عند انتهاء التجربة

```
1. النظام يكتشف انتهاء الفترة
2. البرنامج يُغلق فوراً
3. تظهر شاشة انتهاء التجربة
4. عرض خطط الاشتراك
5. خيارات:
   - اختيار خطة والاشتراك
   - إدخال كود تفعيل
```

### 4. التحول لمشترك مدفوع

```
1. المستخدم يتواصل ويشترك
2. يحصل على كود تفعيل
3. يدخل الكود
4. النظام يقوم بـ:
   - تفعيل الكود
   - تحديث حالة التجربة
   - تسجيل التحويل في الإحصائيات
   - تحديث معدل التحويل
```

## آليات الحماية التفصيلية

### 1. بصمة الجهاز (Device Fingerprint)

تتكون من:
```javascript
- navigator.userAgent
- navigator.language
- navigator.languages
- navigator.hardwareConcurrency
- screen.width, screen.height
- screen.colorDepth, screen.pixelDepth
- timezone offset
- navigator.platform
- navigator.maxTouchPoints
- devicePixelRatio
- navigator.vendor
- WebGL fingerprint (vendor & renderer)
- Canvas fingerprint (رسم معقد + hash)
- Audio fingerprint (تحليل صوتي)
```

النتيجة:
- Hash SHA-256 فريد
- احتمالية التطابق: أقل من 0.00001%
- تخزين محلي مشفر
- نسخة احتياطية على Supabase

### 2. فحص تزامن الوقت

```javascript
كل جلسة:
  1. أخذ وقت العميل
  2. إرسال للخادم
  3. الخادم يرد بوقته الحقيقي
  4. حساب الفرق
  5. إذا الفرق > 5 دقائق:
     - تسجيل كمشبوه
     - إيقاف البرنامج
     - رسالة خطأ
```

### 3. كشف الوضع الخاص

```javascript
طريقة 1: Storage Quota
  - الوضع العادي: > 120MB
  - الوضع الخاص: < 120MB

طريقة 2: IndexedDB
  - محاولة إنشاء DB
  - فشل = وضع خاص
  - نجاح = وضع عادي
```

### 4. منع التجربة المتكررة

```javascript
عند محاولة بدء تجربة جديدة:
  1. فحص البصمة في Supabase
  2. إذا وُجدت جلسة سابقة:
     - فحص حالتها
     - إذا منتهية = رفض
     - إذا نشطة = استعادة
  3. رسالة واضحة للمستخدم
```

### 2. الإحصائيات المتاحة

#### البطاقات الرئيسية
- إجمالي التجارب
- التجارب النشطة
- التجارب المنتهية
- المتحولون لمشتركين
- معدل التحويل
- تجارب اليوم

#### التقارير التفصيلية
- آخر 10 مستخدمين
- حالة كل مستخدم
- عدد جلسات كل مستخدم
- التواريخ والأوقات

#### الميزات الأكثر استخداماً
- قائمة بأكثر 5 إجراءات
- عدد مرات الاستخدام
- رسم بياني

### 3. استعلامات SQL مفيدة

```sql
-- عرض جميع التجارب النشطة
SELECT * FROM trial_sessions
WHERE is_expired = false
AND trial_expires_at > now()
ORDER BY trial_started_at DESC;

-- عرض التجارب المنتهية اليوم
SELECT * FROM trial_sessions
WHERE DATE(trial_expires_at) = CURRENT_DATE
ORDER BY trial_expires_at;

-- عرض المتحولين لمشتركين
SELECT * FROM trial_sessions
WHERE converted_to_paid = true
ORDER BY updated_at DESC;

-- عرض محاولات التلاعب المشبوهة
SELECT * FROM server_time_checks
WHERE is_suspicious = true
ORDER BY created_at DESC;

-- إحصائيات الإجراءات
SELECT action_type, COUNT(*) as count
FROM user_analytics
GROUP BY action_type
ORDER BY count DESC;
```

## استكشاف الأخطاء

### مشكلة: "لا يمكن استخدام البرنامج في وضع التصفح الخاص"

**الحل**: استخدم وضع التصفح العادي

### مشكلة: "تم اكتشاف تلاعب في توقيت النظام"

**الحل**:
1. تأكد من ضبط التوقيت بشكل صحيح
2. فعّل التزامن التلقائي للوقت
3. أعد تشغيل البرنامج

### مشكلة: "لقد انتهت فترة التجربة المجانية"

**الحل**:
1. تواصل مع الدعم للحصول على كود اشتراك
2. أدخل الكود في شاشة التفعيل

### مشكلة: المستخدم يريد تجربة ثانية

**للمطور فقط**:
```sql
-- حذف الجلسة من قاعدة البيانات
DELETE FROM trial_sessions
WHERE device_fingerprint = 'البصمة';

-- أو إعادة تعيين
UPDATE trial_sessions
SET
  trial_expires_at = now() + interval '7 days',
  is_expired = false
WHERE device_fingerprint = 'البصمة';
```
